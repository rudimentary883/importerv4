1. Choose Import Mode

This controls how many speakers are attached to each team during API import. BP imports the first 2 speakers per team, 3v3 imports up to 3, and WSDC imports up to 5 (warns if a team has fewer than 3).

If your token keeps failing (especially on Calico-hosted sites), you can provide your admin username and password as a fallback. The importer will try token auth first, then log in via Django session if needed.

3. Upload Your Data Files

Importing in batches? In Direct API Import mode the importer first reads what is already on your tab site. Anything that already exists (same institution code/name, same team, same judge, same speaker on the same team) is skipped, and only the new entries are imported. So you can upload the same, updated .csv files again and again, or upload only the new rows. Every file is optional: you can import just a few teams or judges into institutions that are already on the site without uploading the institutions file.

📋 Institutions (optional)

Columns: name, code — Code is the short name used in other files (e.g., UNSW, ANU). Only needed for new institutions. Teams and judges can use institutions that are already on the tab site.

⚖️ Adjudicators

Columns: name, institution, email, gender, base_score, independent, adj_core, notes

👥🎤 Teams + Speakers in ONE file (optional)

One row per team, with its speakers side by side. You do not need the separate Teams and Speakers files for these teams, and you can paste a Google Form responses sheet as it is: columns such as Name of Speaker 1, Email Address of Speaker 1, Gender of Speaker 1, Team Name, Full Name of Institution are recognised automatically. Rows that are not teams (e.g. adjudicator registrations) are skipped.

Standard layout (what the template contains)

Team columns: institution, reference, short_reference, code_name, use_institution_prefix, emoji, team_name (human)
then for each speaker N (1 to 5): speaker_N_name, speaker_N_gender, speaker_N_email, speaker_N_phone, speaker_N_anonymous, speaker_N_categories
Leave the unused speaker columns blank: a WSDC team with only speakers 1–3 filled in is read as a 3-speaker team (no error).
